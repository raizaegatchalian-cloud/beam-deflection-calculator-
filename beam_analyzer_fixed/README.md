# Beam Analyzer (fixed layout)

1. Extract this ZIP file.
2. Open the extracted `beam_analyzer_fixed` folder.
3. Click the address bar, type `cmd`, and press Enter.
4. Run `python main.py`.

If needed, install dependencies with `python -m pip install numpy matplotlib`.

The Analysis Method selector and Calculate Beam button are now placed above the added-load list so they remain visible on high-DPI Windows displays.
